# 사진 EXIF 기반 이동 경로 재생 설계

## 목표

사용자가 여행 사진 여러 장을 선택하면 브라우저에서 촬영 시각과 GPS 좌표를 읽고, 촬영 순서에 따라 지도 위에서 실제 시간 간격에 비례한 이동 애니메이션을 재생한다. 사진 원본과 추출한 메타정보는 Firebase나 다른 서버로 전송하지 않는다.

## 범위

- 여러 사진을 한 번에 선택한다.
- EXIF `DateTimeOriginal`과 GPS 위도·경도를 브라우저에서 추출한다.
- 유효한 사진을 촬영 시각순으로 정렬한다.
- 사진 좌표 사이를 직선 보간하여 현재 위치 마커를 움직인다.
- 지나온 구간만 지도에 점진적으로 그린다.
- 현재 사진, 촬영 날짜와 시각, 사진 순번, 진행률을 표시한다.
- 재생, 일시정지, 처음부터, 진행바 이동, `0.5x`, `1x`, `2x` 속도를 제공한다.
- 기존 계획 일정 지도는 유지하고 사진 이동 경로는 별도 재생 모드와 색상으로 표시한다.

다음 항목은 범위에서 제외한다.

- 사진 또는 메타정보의 Firebase Storage·Firestore 저장
- 두 사진 사이의 실제 도로·도보 경로 계산
- 사진 편집, 클라우드 동기화, 사용자 간 사진 공유
- 새로고침 이후 재생 상태 복원

## 사용자 흐름

1. 사용자가 지도 영역의 `사진으로 이동 경로 재생` 기능에서 사진을 선택한다.
2. 앱은 로컬 파일을 메모리에서 읽고 처리 상태를 표시한다.
3. 분석이 끝나면 유효한 사진 수와 제외된 사진 수·이유를 보여준다.
4. 유효 좌표가 두 개 이상이면 지도 범위를 경로 전체에 맞추고 재생 준비 상태가 된다.
5. 사용자가 재생을 누르면 첫 사진부터 마지막 사진까지 시간 비율에 맞춰 마커와 경로가 움직인다.
6. 진행바 이동이나 처음부터 기능을 사용하면 지도, 현재 사진, 시각 표시가 동일한 재생 시점으로 갱신된다.
7. 새 사진을 선택하거나 페이지를 새로고침하면 이전 로컬 데이터와 미리보기 URL을 해제한다.

## 구조

### EXIF 읽기

클라이언트 측 EXIF 파서를 사용해 각 파일에서 촬영 시각과 GPS를 읽는다. 앱 코드에는 `extractPhotoMetadata(file)` 경계를 두어 파서 종속성을 격리한다. 지원 이미지이지만 필수 태그가 없으면 오류로 중단하지 않고 제외 사유를 기록한다.

### 경로 데이터 구성

정규화 결과는 다음 형태를 사용한다.

```js
{
  id,
  file,
  previewUrl,
  capturedAt,
  lat,
  lng
}
```

`capturedAt` 오름차순으로 안정 정렬한다. 동일 촬영 시각은 파일 선택 순서를 유지한다. 연속된 동일 좌표도 사진 전환을 위해 항목은 보존하되 이동 거리는 0으로 처리한다.

### 시간 압축

원본 촬영 시간 간격의 상대 비율을 유지한다. 화면 재생이 비현실적으로 오래 멈추는 것을 방지하기 위해 개별 구간의 반영 간격에는 상한을 둔 뒤 전체를 목표 재생 시간으로 정규화한다. 기본 목표 재생 시간은 사진 수와 구간 수를 고려하되 사용자가 기다리지 않도록 제한된 범위 안에서 계산한다. 재생 속도는 정규화된 시간축에 배율로 적용한다.

### 애니메이션

`requestAnimationFrame`으로 현재 재생 시각을 계산한다. 해당 시각이 속한 두 사진 좌표를 찾고 선형 보간하여 마커 위치를 결정한다. 완료된 좌표와 현재 보간 좌표를 합쳐 지나온 polyline을 다시 그린다. 지도, 진행바, 현재 사진 정보는 동일한 재생 상태를 입력으로 사용해 서로 어긋나지 않게 한다.

### UI 통합

기존 Leaflet 지도와 계획 일정 경로를 재사용한다. 지도 제어 영역에 사진 선택 및 재생 모드 진입점을 추가하고, 지도 아래에 재생 컨트롤과 현재 사진 패널을 둔다. 사진 경로 레이어와 계획 일정 레이어는 별도로 관리하여 사진을 다시 선택하거나 재생을 초기화해도 기존 일정 지도를 손상하지 않는다.

## 오류와 예외 처리

- GPS가 없는 사진: 경로에서 제외하고 개수와 이유를 표시한다.
- 촬영 시각이 없는 사진: 시간순 재생에 사용할 수 없으므로 제외한다.
- 손상되었거나 지원하지 않는 파일: 해당 파일만 제외하고 나머지를 계속 처리한다.
- 유효 사진 0장: 지원되는 메타정보가 없다는 안내를 표시한다.
- 유효 사진 1장: 단일 위치와 사진은 표시하되 이동 재생은 비활성화한다.
- 동일 시각·동일 좌표: 선택 순서를 유지하며 안전하게 즉시 또는 정지 구간으로 전환한다.
- 대량 사진: 파일을 순차 또는 제한된 동시성으로 분석해 브라우저 멈춤과 메모리 급증을 줄인다.
- 화면 이탈·새 선택: 애니메이션 프레임을 취소하고 생성한 object URL을 해제한다.

## 개인정보 보호

- 파일 입력에서 받은 `File` 객체만 브라우저 메모리에서 처리한다.
- 사진, EXIF 결과, 미리보기 Blob URL을 Firestore, Firebase Storage, 분석 도구 또는 외부 API로 전송하지 않는다.
- 페이지 안내문에 로컬 처리임을 명시한다.
- 새 선택과 페이지 종료 시 가능한 미리보기 URL을 해제한다.

## 테스트와 검증

- EXIF 시각과 GPS가 모두 있는 사진이 올바르게 정렬되는지 확인한다.
- GPS 또는 촬영 시각이 없는 사진이 제외되고 이유가 집계되는지 확인한다.
- 동일 시각, 동일 좌표, 날짜 변경, 장시간 공백을 포함한 시간축 계산을 검증한다.
- 재생, 일시정지, 재개, 처음부터, 진행바 이동, 속도 변경의 상태 일관성을 검증한다.
- 경로가 첫 좌표에서 시작해 마지막 좌표에서 정확히 끝나는지 확인한다.
- 기존 일정 지도 필터와 마커 동작이 유지되는지 회귀 검증한다.
- 모바일 화면에서 파일 다중 선택과 재생 컨트롤이 사용 가능한지 확인한다.
- 네트워크 요청을 관찰해 사진 데이터와 EXIF 값이 외부로 전송되지 않는지 확인한다.

## 완료 기준

- 유효한 원본 사진 두 장 이상을 선택하면 촬영 시각순 이동 애니메이션을 재생할 수 있다.
- 사진 간 촬영 시간 비율이 상한 처리 후 재생 시간에 반영된다.
- 재생 중 지도 경로, 마커, 사진, 시각, 진행률이 일치한다.
- 필수 EXIF가 없는 사진 때문에 전체 처리가 실패하지 않는다.
- 사진과 메타정보가 서버 또는 외부 서비스로 전송되지 않는다.
- 기존 계획 일정과 지도 기능에 회귀가 없다.
